#Mi primer Bot de Telegram con Python

Ese repositorio contiene el codigo para crear un bot de Telegram utilizando la biblioteca Telebot
de python.



##Configuracion 
    1. Clona este repositorio
    2. Instala las dependencias usando 'pip install -r requirements.txt'
    3. Crea un bot en Telegran usando BotFather y obten tu token
    4. Remplaza 'TU_TOKEN_AQUI' en 'main.py' con tu token de BotFather 
    5. ejecuta el bot usuando 'python main.py'

    ## Funcionalidades:

    --Responde alos comandos '/start' y '/help'
    --Repite cualquier otro mensaje que le envies
